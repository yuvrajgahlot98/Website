# Skillpath Courses

A Framer React code component for the Skillpath course-catalogue assignment.

## Use in Framer

1. Create a code component in Framer.
2. Paste the contents of `SkillpathCourses.tsx`.
3. Add it to the page and publish the page from Framer.

The component includes the hero CTA, courses section, and footer. Build any additional page layout in Framer as needed.

## Assignment behaviour

- Fetches the required GET endpoints from `https://syncsphere-hiv6.onrender.com`.
- Handles loading, course-fetch failures, country-fetch failures, and empty course data.
- Converts `pricePaise / 100` to Indian rupees and `priceUsdCents / 100` to US dollars.
- Uses a three-column desktop, two-column tablet, and one-column mobile grid.
- Provides two Framer property controls: heading and accent color.
- Includes optional search, price sorting, skeleton loaders, retry actions, and refundable badges.
